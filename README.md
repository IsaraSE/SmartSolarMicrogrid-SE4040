# Smart Solar Microgrid Trading System (SE4040)

This is the central repository for the SE4040 Smart Solar Microgrid Trading System.

## Project Structure

- `backend/SmartSolarMicrogrid.Api`: C# ASP.NET Web API backend
- `web/SmartSolarMicrogrid.Web`: Web application
- `android/SmartSolarMicrogridMobile`: Pure Native Android application
- `database/`: Database documentation and sample data
  - `sample-data/`: MongoDB sample data
  - `design/`: Database design documents
- `docs/`: Documentation and report assets
  - `architecture/`: Architecture diagrams and notes
  - `diagrams/`: UML and system diagrams
  - `screenshots/`: UI screenshots
  - `report/`: Final report documents
  - `viva/`: Viva presentation materials
- `deployment/iis/`: IIS deployment-related documentation and configuration

## Contributing

Each member will create their own feature files in the respective directories.
